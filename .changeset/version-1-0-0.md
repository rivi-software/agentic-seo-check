Agentic SEO Check is 1.0.0: what agents and CI depend on now follows semantic versioning (issue #150). That is each rule's id, severity, message and recommendation, the MCP tools' names and input schemas on the local and the hosted server, the CLI's flags and exit codes, and the audit JSON (`schemaVersion: 1`). Renaming, removing or changing the meaning of any of them now needs a major version. Before, a minor version could.

Nothing else changes from 0.22.0: the rules, the tools, the flags and the JSON are the same.
